# 학회 마감 지도 (CS · Robotics)

아직 논문 제출이 가능한 전 세계 컴퓨터과학·로보틱스 학회를 지도에 표시합니다.
매일 아침 6시(한국 시간)에 GitHub Actions가 자동으로 갱신합니다.

**지도 보기:** https://kbh1795-sketch.github.io/conf-deadline-map/

- 데이터 출처: [ccfddl/ccf-deadlines](https://github.com/ccfddl/ccf-deadlines) (마감일·장소·CCF/CORE 등급)
- 장소 좌표: OpenStreetMap Nominatim (`geocache.json`에 저장해 재사용)
- 빠진 학회는 `extra/robotics.yml`에 같은 형식으로 추가
- 수동 갱신: Actions 탭 → *Update map* → *Run workflow*
